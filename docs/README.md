# Documentation Index

Knowledge base for this project. Keep it navigable — this README is the entry point.

| Section | Contents |
|---|---|
| `architecture/` | System-shaping documents: technical architecture, ecosystem/product structure, shared-layer design |
| `product/` | Per-category or per-product deep-dive specs |
| `strategy/` | Brand, domain, UI/UX, GTM, monetization, competitive, roadmap, metrics |
| `decisions/` | Landed ADRs (`ADR-NNNN-Title.md`) — `TEMPLATE.md` starts a new one, `EXAMPLE-ADR-*` shows a real one |
| `legal/` | Code-adjacent legal docs (corporate docs belong in a private company-ops repo) |

## Conventions

- **Pending** proposals live in `/rfcs`, not here — an RFC graduates into an ADR when accepted.
- ADRs are never silently rewritten; amendments are appended with a date.
- Link ADRs and specs from the `product.md` of any product that depends on them.
